## Design Concepts

### Design 1: **Minimal Single Column** ✅ CREATED
**Style**: Clean, focused, maximalist white space
**Layout**: Everything stacked vertically in a single 900px centered column
**Key Features**:
- Gradient purple heading
- Soft shadows on white cards
- Simple multi-select dropdown for passports
- Dropdown for savings with preset values
- Large, prominent explore button
- Grid-based legend at bottom
- Perfect for: Users who want simplicity and focus

**Preview**: Open `mockup-1-minimal.html` in your browser

---

### Design 2: **Card-Based Layout**
**Style**: Modern card UI with distinct sections
**Layout**: Cards floating on light gray background, 2-column grid for inputs
**Key Features**:
- Each input group in its own card
- Soft card shadows with hover effects
- Icon-based labels
- Colorful accent colors for each section
- Sticky header on scroll
- Perfect for: Visual organization and scanning

---

### Design 3: **Sidebar + Map**
**Style**: Dashboard-style with collapsible sidebar
**Layout**: Left sidebar (300px) with controls, map takes 70% of screen
**Key Features**:
- Collapsible sidebar for more map space
- Hamburger menu on mobile
- Fixed sidebar with scrolling
- Map always visible while filling out form
- Compact input layout
- Perfect for: Power users who want efficiency

---

### Design 4: **Compact Horizontal**
**Style**: Dense, information-rich single row
**Layout**: All controls in one horizontal row above map
**Key Features**:
- Ultra-compact 4-column layout
- Inline labels
- Minimal padding
- Smaller text, more info density
- Quick-access design
- Perfect for: Desktop power users with large monitors

---

### Design 5: **Modern Gradient**
**Style**: Bold, colorful, Instagram-style gradients
**Layout**: Centered column with vibrant colors
**Key Features**:
- Bright gradient backgrounds
- Glass-morphism effects
- Animated button hovers
- Colorful shadow effects
- Modern typography (larger, bolder)
- Perfect for: Eye-catching, modern aesthetic

## Key Improvements in ALL Designs

✅ **Passport Selector**: Changed from grid to multi-select dropdown
   - Hold Ctrl/Cmd to select multiple passports
   - Much more compact
   - Native browser UX

✅ **Savings Input**: Changed from buttons to dropdown
   - Preset options: $1K, $5K, $10K, $20K, $30K, $50K, $100K, $200K
   - Saves ~150px of vertical space
   - Cleaner appearance
